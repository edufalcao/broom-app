## Broom v1.4.0 - Deeper Cleaning, Clearer Trust

**Broom 1.4.0** cleans far more of what browsers and developer tools leave behind, shows you exactly what safety rules blocked during cleanup, and stops blocking threads during uninstalls.

---

### System Cleaner
- Browser cache cleaning now covers GPU, shader, and CRX component caches for Chromium browsers, with per-cache labels such as "Chrome — GPUCache"
- Ten more browsers supported: Vivaldi, Opera, Yandex, Orion, Zen, Comet, Helium, QQ Browser, Thunderbird, and Dia
- Saved Application State and Messages sticker caches are now offered under System Caches
- New developer cache targets: Cargo Registry, Bun, Corepack, rbenv downloads, RubyGems Specs, and Bundler
- New Simulator Data category cleans simulator caches, CoreSimulator logs, and per-device temp files — automatically skipped while Xcode or Simulator is running

### Trust
- Cleaner and Uninstaller completion screens now show how many items were blocked by safety rules instead of silently skipping them
- LaunchServices database refresh no longer blocks a thread while uninstalling

### Quality
- 185 tests across 28 suites, plus a new UI smoke-test target with code coverage enabled in CI
